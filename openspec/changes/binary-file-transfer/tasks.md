- [ ] 3.2 Streaming writer: `async def stream_to_vault(row, chunks: AsyncIterator[bytes], *, max_bytes, content_length: int | None, deadline: float, idle_timeout: float, before_publish: Callable[[], Awaitable[bool]]) -> dict(size, sha256, mime)` using §2: early `Content-Length` reject; count; abort at cap+1 (`TooLarge`); per-chunk `asyncio.wait_for(idle_timeout)` and overall monotonic deadline (`Timeout`); sha256 + `classify_bytes(first_8k, name)`; call `before_publish()` which opens the locking transaction (`lock_for_publish` + identity/root re-validation) and returns a context that stays open across `publish`; publish per row (`overwrite`/`expected_fingerprint`; a null fingerprint on an overwrite token = target must be absent → 409 otherwise); complete + usage-log row committed inside that same transaction; cleanup on any exception.
