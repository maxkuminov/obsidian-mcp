**The seam is one template variable.** Slice A writes `nonce="{{ csp_nonce }}"` on every `<script>` and `<style>`; Slice B provides `csp_nonce` through a context processor on the four panel/auth/consent `Jinja2Templates` instances (design D7). Until both land, A's templates render an empty nonce (Starlette's default `Undefined`) and B's nonce-equality test has no nonces to compare. B's header test is therefore authoritative **only on the merged tree** (task 4.2). Neither slice renames the variable.

**Base check for every subagent brief.** Agent worktrees branch from `origin/main`, not local HEAD. Open each brief with: confirm `openspec/changes/panel-csp/proposal.md` and `openspec/changes/archive/2026-09-22-asvs-edge-hardening/` both exist. If not, stop and report.
