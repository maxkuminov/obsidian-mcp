# Tasks — internal-transport-tls (#184, #185 application half)

Two slices with one shared new module. Slice A owns the database hop, Slice B the embedding hop; `src/services/transport_security.py` is **created by Slice A** with the database helpers, and Slice B appends its section (embedding URL classification, client factory, embedding report) after A merges — or the two run sequentially. `src/config.py` is touched by both in **separate, named regions** (A: a `DATABASE_SSL_*` block directly under `database_url`; B: `embedding_allow_plaintext` / `embedding_ca_file` directly under `openai_embedding_model`, and its validator after `_validate_provider_credentials`). `src/main.py`'s lifespan belongs to A; B's startup report call is a one-line seam the supervisor wires at merge (6.2).

**Base check for every subagent brief.** Confirm `openspec/changes/internal-transport-tls/proposal.md` and `openspec/changes/archive/2026-09-22-asvs-edge-hardening/` both exist. If not, stop and report.
