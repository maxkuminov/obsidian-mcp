# Project conventions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository. It is
the canonical source for project conventions, commands, validation gates,
architecture decisions, and documentation requirements for both Claude and Codex.

Also read the shared engineering workflow at
`~/.claude/rules/engineering-workflow.md`, as required by `CLAUDE.md`. The explicit
project-specific overrides in `CLAUDE.md` take precedence over that workflow.
If the shared file is unavailable, report that limitation and continue with the
available project instructions. Claude-specific tools, model names, and slash
commands require an available equivalent; do not claim an unavailable gate ran.

Keep shared project conventions in `CLAUDE.md` so both agents use the same
instructions. Follow its architecture-note links before changing the relevant
area, and update those notes in the same change.
